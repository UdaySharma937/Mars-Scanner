### 🌌 About MarsScanner

**MarsScanner** is a powerful, open-source Web URL Scanner built for Bug Bounty Hunters, Penetration Testers, and Cybersecurity Researchers.

Its mission: Explore every corner of a domain like we explore Mars.  
Find hidden `subdomains` and `directories` to map the complete attack surface. With 1,000,000+ auto-generated wordlists and recursive scanning, discover admin panels, APIs, backup files, and forgotten assets in minutes.

No paid tools. No manual setup. Deploy 100% free.

### ✨ Key Features

-  **Dual Scanner Engine**  
  Separate modules for `Subdomain Enumeration` and `Directory Bruteforce`.
-  **1,000,000+ Wordlist**  
  Auto-generates 500k Subdomains + 500k Directories on first run.
-  **Recursive Scan**  
  Goes 1 level deep. Found `/admin`? It will scan `/admin/login` too.
-  **High Speed**  
 150 concurrent async requests with `FastAPI` + `aiohttp`.
-  **Live Dashboard**  
  Real-time progress, filters for `200, 301, 403`, and search.
-  **Export Reports**  
  Download results in `TXT`, `CSV`, or `PDF` with 1 click.
-  **Modern UI**  
  Dark, clean, mobile-responsive dashboard with `React` + `TailwindCSS`.
